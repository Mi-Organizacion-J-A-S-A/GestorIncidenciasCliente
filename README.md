# GestorIncidenciasCliente
Gestor de Incidencias Informáticas. Gestor del Cliente


El cliente puede introducir las incidencias informáticas que ocurren en el Centro Educativo.
Dará los datos del aula, equipo y podrá incorporar además de una descripción del error,  una imagen.
El técnico, desde otra aplicación móvil podrá resolverlas y cambiar el estado de dichas incidencias.
